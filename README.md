# Singtel Case Triage — prototype (Streamlit + OpenAI API version)

Decision-support prototype for complex, repeated, unresolved Singtel home-broadband
cases. Built as a backup deployment path after a Copilot Studio environment licence
issue blocked publishing a public demo link.

Synthetic data only. No connection to any live Singtel system.

## What it demonstrates

1. **Input** — a synthetic case (form fields + free-text customer message).
2. **AI processing** — a real OpenAI API call classifies Intent, Complexity,
   Urgency, Sentiment, missing information, and produces a grounded summary.
3. **Deterministic rule layer** — a plain Python function (`calculate_priority`)
   calculates the priority score and escalation recommendation from the
   classified factors. This is intentionally separate from the AI model call,
   so the scoring logic is transparent and auditable.
4. **Human decision** — Accept / Modify / Escalate buttons. A "No decision"
   button is included to demonstrate the no-approval control path.
5. **Simulated business action** — a simulated ticket ID and timestamp are
   generated by the app's own code, only after a valid decision. They are
   never produced by the language model.

## Run it locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

You will be asked for your own OpenAI API key in the sidebar. The key is only
held in the running session and is never written to disk or sent anywhere
except directly to the OpenAI API.

## Deploy for a public shareable link (Streamlit Community Cloud)

1. Create a free account at https://share.streamlit.io (sign in with GitHub).
2. Push this folder to a **public** GitHub repository.
3. On Streamlit Community Cloud, click "New app", pick the repository and
   `app.py` as the entry point, then click "Deploy".
4. Once deployed, the app gets a public URL such as
   `https://<your-app-name>.streamlit.app` — this is the shareable link for
   the assessment submission.
5. Do **not** put your OpenAI API key in the repository. Each visitor enters
   their own key in the sidebar at runtime. If you want a single shared key
   for markers to test with, use Streamlit's "Secrets" feature in the app
   settings instead of hardcoding it, and mention in your report that the key
   is supplied via Streamlit secrets, not committed to source control.

## Deploy alternative: Hugging Face Spaces

1. Create a free account at https://huggingface.co.
2. Create a new Space, choose the "Streamlit" SDK.
3. Upload `app.py` and `requirements.txt` (or push via git).
4. The Space gets a public URL automatically once it builds.

## Notes for the report

- The AI processing step (classification + summary) is a genuine, live call to
  the OpenAI API — this satisfies the "API integration" category of genuine AI
  functionality.
- The priority scoring step deliberately does **not** call the AI model; it is
  a fixed, auditable Python function, matching the "automation logic" category
  and directly answering the marking note about proving a deterministic rule
  layer exists separately from the language model.
- The escalation thresholds and point weights in `calculate_priority` are
  prototype design rules for this assessment, not existing Singtel policy.
